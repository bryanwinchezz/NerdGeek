# 🎮 NerdGeek

**NerdGeek** é o seu portal de notícias Nerd e Geek — cobrindo o melhor do mundo dos games e do entretenimento. Com suporte a PWA, painel de administração e identidade visual própria.

## 📋 Sobre o Projeto

O **NerdGeek** é um portal de notícias voltado para a cultura geek: games, filmes, séries, animes, quadrinhos e tudo que o universo nerd tem de melhor. O projeto conta com uma interface de leitura limpa, painel de administração para gerenciamento de conteúdo e suporte a PWA para acesso rápido via celular.

## ✨ Funcionalidades

- Portal de notícias sobre games e entretenimento geek
- Painel de administração para gerenciar conteúdo
- PWA com service worker para uso offline e instalação no celular
- Identidade visual geek com ícones próprios
- Layout de portal de notícias responsivo

## 📱 PWA — Progressive Web App

O NerdGeek suporta instalação como app via PWA, com service worker registrado para cache offline e ícones específicos para a tela inicial do dispositivo.

## 🚀 Como Executar

```bash
# Clone o repositório
git clone https://github.com/bryanwinchezz/NerdGeek.git

# Para testar o PWA, use um servidor local
python3 -m http.server 8000

# Acesse em
http://localhost:8000
```

## 🛡️ Painel Administrativo

O portal inclui uma página separada de administração (`gerenciador-de-adm-nerdgeek.html`) para gerenciar publicações, categorias e conteúdo do portal.
